**Rechiseled: Applied Energistics 2** adds integration between Applied Energistics 2 and Rechiseled! The mod allows for autocrafting of recipes from Rechiseled with the storage systems from Applied Energistics 2 as well as adding 100+ new decorative variants of blocks in Applied Energistics 2!

![Separator](https://imgur.com/0MeNaUZ.png)

### Chiseling Patterns

The Chiseling Pattern Encoder is a new block that allows you to pick an input and output entry from chiseling recipes and encode them into a Chiseling Pattern. The chiseling pattern can then be used with a Molecular Assembler to allow for autocrafting similar to regular crafting recipes. 
(As a bonus, the Chiseling Pattern Encoder also displays the selected entry on top of the block, making it great for decoration!)
